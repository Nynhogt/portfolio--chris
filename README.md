# Portfólio — Chris

Site estático de portfólio para UX/UI e Product Design. Não precisa instalar dependências: abra `index.html` no navegador ou publique o repositório diretamente na Vercel.

## Personalização

- Atualize nome, apresentação, projetos e links em `index.html`.
- Troque o e-mail de exemplo `seuemail@exemplo.com` pelo contato profissional.
- Ajuste cores, tipografia e layout em `styles.css`.

## Publicar na Vercel

Importe este repositório em [vercel.com/new](https://vercel.com/new). A Vercel detecta o site estático automaticamente; não é necessário configurar build command nem output directory.
